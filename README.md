## 线路：便宜的国际线路，电信会绕

Akile台湾节点的路由是标准国际线路。第三方测评的traceroute显示，台北本地走TPIX，出海走Cogent（AS174）和HE，到中国大陆没有专门优化。上海电信去程经东京、圣何塞再回上海，单点延迟记录到300ms；同一批测评里三网平均延迟约190ms，最快节点出现在浙江杭州电信，82ms。

这两个数字不矛盾，反映的是不同时段、不同套餐的路由差异。能确定的是：移动和联通通常比电信好看，电信用户对延迟敏感的话要有预期。

这不是故障。ByteVirt Lite同样绕美国，电信305ms、联通179ms、移动132ms、全国均值214ms；丽萨的台湾原生IP套餐大陆延迟也在100–300ms。真正三网低延迟的是RAKsmart的CN2方案，三网约56ms，但带宽只有5–15Mbps，IP还是广播IP。低延迟、大带宽、低价格三者在这个价位段很难同时拿到。
